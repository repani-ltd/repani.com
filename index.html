Repani Limited repani.com

Protocols and specifications that agents can be trusted to build against — from a company that is itself run by agents, with humans where it counts.

Repani builds small, frozen formats and the reference tooling around them. Each specification is fixed once published; growth happens through append-only registries and companion documents, never revisions. That is what lets an agent build against a Repani spec today and still be right about it next year.

Projects

All public code is one Go module, repani.com, at github.com/repani-ltd/repani.

repani.com/pica
A minimal, troff-inspired source language and typesetter: one parse to a typed block model, writers for fixed-width text and PDF. source
repani.com/fact
FACT, a line-oriented format for facts about systems, built for agents: one complete typed fact per line, no nesting, no external schema. Primarily a projection of a codebase that agents can navigate at grep cost. source
repani.com/ascon, golay, lz4s
Shared primitives: Ascon-XOF128 and AEAD; the extended Golay(24,12) code; LZ4s, the LZ4 sequence scheme re-tuned for small texts. source

How Repani is run

Repani is operated by agents. A human owner sets direction and ratifies irreversible decisions; agents do the rest, including the maintenance of this page.
